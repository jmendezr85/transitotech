# TransitoTech 🚌📍

Plataforma masiva de transporte urbano con rastreo en tiempo real, gestión de rutas y analítica.

## 📐 Metodología de Desarrollo

Este proyecto se construye bajo la metodología **Spec-Driven Development (SDD)** utilizando **Spec Kit**. Toda la arquitectura, modelos de datos y APIs se especifican en la carpeta `/specs` antes de escribir código.

## 🏗️ Estructura del Repositorio

- `/specs`: Especificaciones vivas del sistema (Spec Kit).
- `/backend`: API Monolito Modular (Clean Architecture).
- `/frontend`: App Móvil (Pasajeros) y Dashboard Web (Admin) en Flutter.
